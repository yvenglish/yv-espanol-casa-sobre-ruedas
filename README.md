# Una casa sobre ruedas — YV Español

Projeto estático pronto para GitHub Pages.

## Publicação

1. Extraia o ZIP.
2. Envie `index.html`, `styles.css`, `script.js` e a pasta `assets` para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Selecione **Deploy from a branch**, a branch `main` e a pasta `/ (root)`.

O áudio prioriza a voz `es-ES` disponível no navegador.
